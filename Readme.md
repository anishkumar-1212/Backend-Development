## ▶️ Running the Project

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project folder:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Run the server:

```bash
node app.js
```

Or, if using Nodemon:

```bash
nodemon app.js
```
